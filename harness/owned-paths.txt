# Paths that harness/scripts/update.sh copies from the harness repository into a project.
# One path per line, relative to both repositories. Directories end with a slash and are synced
# with --delete. A path with * copies each match on its own: `.claude/skills/*/` syncs every
# harness skill and keeps the skills of the project. `src => dst` copies a file from the harness
# path src to the project path dst. Lines starting with # are comments. Paths under [diff-only]
# are shown as a diff and not overwritten, because the project owns them after the first copy.
# Paths under [remove] were harness-owned and are deleted in the project; only paths under
# .claude/, .github/, .githooks/ and harness/ are accepted.
