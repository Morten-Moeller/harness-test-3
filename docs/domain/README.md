# Domain

Die Fachsprache des Projekts. Code, Specs und Gespräche verwenden die Begriffe aus
`glossary.md` genau so. Ein neuer Begriff wird zuerst hier angelegt, dann im Code verwendet.
Skill: `/domain`.

| Datei | Inhalt |
|---|---|
| `glossary.md` | Begriffe, Definitionen, Synonyme, die nicht verwendet werden |
| `contexts.md` | Bounded Contexts, ihre Grenzen und Beziehungen (anlegen, sobald es mehr als einen gibt) |
| `invariants.md` | Regeln, die immer gelten müssen, mit der Stelle im Code, die sie durchsetzt |
